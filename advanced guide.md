# Java
## advanced guide
### bytecode
#### look at bytecode in VSC
If one want to look at bytecode of `ByteCodeExample1.java` file.

1. Install `Show Java ByteCode` plugin in VSC marketplace.
2. Compile `ByteCodeExample1.java` file and will generate `ByteCodeExample1.class` by default.
3. Open `ByteCodeExample1.class`.
4. Click `Show ByteCode` at right top of panel.

The demo video is available at [YT](https://youtu.be/dOfADvT2Mq0).
